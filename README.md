## Do poste ao código

Sou o Pedro, estudante de **Engenharia de Software na UNINTER** e atuo em **TI e Telecomunicações na Âmbar Energia** em Boa Vista (RR), com base técnica como eletricista de distribuição.

No campo aprendi a seguir procedimento à risca (NR-10, NR-35), levar segurança a sério e resolver o problema com o cliente esperando. Levo o mesmo método para o código: entender o problema de perto, seguir um passo a passo e testar antes de entregar. No longo prazo, quero construir **software para energia e automação industrial**.
